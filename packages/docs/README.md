# Boreal UI Docs

Generated component prop metadata for documentation sites and developer tooling.

```sh
npm install @boreal-ui/docs
```

```ts
import { buttonPropDocs, dataTablePropDocs } from "@boreal-ui/docs";
```

This package is optional and is not required to use `@boreal-ui/core` or
`@boreal-ui/next`. Its version tracks the corresponding Boreal UI release.
