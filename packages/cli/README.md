# Boreal UI CLI

Standalone CLI for configuring Boreal UI in existing React and Next.js apps.

```sh
npm install --save-dev @boreal-ui/cli
npx @boreal-ui/cli init --framework next
```

The CLI installs the framework-specific runtime package, `@boreal-ui/core` or `@boreal-ui/next`, instead of installing the legacy all-in-one `boreal-ui` package.
